## “Creating Access Keys and setting up AWS CLI v2”

Bài demo thực hiện ba việc chính:

1. Tạo Access Key cho IAM user trong các AWS account.
2. Cài AWS CLI phiên bản 2 trên Windows, macOS hoặc Linux.
3. Cấu hình CLI để gửi lệnh đến đúng AWS account.

## 1. Access Key dùng để làm gì?

Access Key cho phép AWS CLI, SDK và chương trình gọi AWS API.

Một bộ Access Key gồm:

```
Access Key ID
Secret Access Key
```

Có thể hiểu gần đúng:

```
Access Key ID     ≈ username
Secret Access Key ≈ password
```

Secret chỉ được hiển thị khi tạo. Nếu làm mất, bạn phải tạo key mới; không thể yêu cầu AWS hiện lại.

## 2. Tạo Access Key

Đăng nhập bằng `IAMadmin`, sau đó vào:

```
IAM
→ Users
→ IAMadmin
→ Security credentials
→ Access keys
→ Create access key
```

Khi AWS hỏi mục đích sử dụng:

1. Chọn **Command Line Interface (CLI)**.
2. Đọc cảnh báo và xác nhận.
3. Có thể thêm description như `local-aws-cli`.
4. Nhấn **Create access key**.
5. Tải file `.csv` hoặc lưu key vào password manager an toàn.

Không gửi Access Key hoặc Secret Access Key vào ảnh chụp, GitHub, email hay đoạn chat. AWS cũng khuyến nghị dùng thông tin xác thực tạm thời thay cho IAM-user Access Key dài hạn khi có thể. AWS IAM – Manage access keys
