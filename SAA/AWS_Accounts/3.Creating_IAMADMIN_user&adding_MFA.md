## Creating IAMADMIN user & adding MFA

Mục tiêu của bài demo là:

1. Tạo một IAM user có quyền quản trị.
2. Dùng user này thay cho root user trong công việc hằng ngày.
3. Bảo vệ tài khoản bằng MFA.
4. Kiểm tra đăng nhập qua IAM sign-in URL.

### 1. Vì sao cần tạo IAMADMIN?

Khi tạo AWS account, bạn có **root user**. Root có quyền tuyệt đối và thực hiện được một số thao tác nhạy cảm mà IAM user không làm được.

Vì vậy:

- Root chỉ nên dùng cho các tác vụ bắt buộc.
- Không dùng root để quản trị AWS hằng ngày.
- Công việc thường ngày nên dùng một IAM administrative user được bảo vệ bằng MFA.

Trong bài, user đó có tên `IAMadmin`.

### 2. Tạo account alias

IAM user thường đăng nhập bằng URL dạng:

```
https://<account-id>.signin.aws.amazon.com/console
```

Account ID gồm nhiều chữ số nên khó nhớ. Account alias cho phép tạo URL dễ đọc hơn:

```
https://<account-alias>.signin.aws.amazon.com/console
```

Alias chỉ giúp đăng nhập thuận tiện; nó không thay đổi quyền hay bảo mật của tài khoản.

### 3. Tạo IAM user

Trong IAM:

```
Users → Create user → IAMadmin
```

Bài demo bật quyền truy cập AWS Management Console và đặt console password.

Hai lựa chọn password thường gặp:

- Mật khẩu tự tạo hoặc AWS tạo tự động.
- Bắt buộc user đổi mật khẩu trong lần đăng nhập đầu tiên.

Console password chỉ dùng cho đăng nhập giao diện web. Nó không phải Access Key.

### 4. Cấp quyền Administrator

Bài demo gắn trực tiếp AWS-managed policy:

```
AdministratorAccess
```

Policy này về cơ bản cho phép mọi action trên mọi resource:

```
{
  "Effect": "Allow",
  "Action": "*",
  "Resource": "*"
}
```

Đây là user quản trị nên quyền rất lớn, nhưng vẫn không hoàn toàn giống root user. Một số thao tác cấp tài khoản chỉ root mới thực hiện được.

Trong môi trường production, nên áp dụng least privilege và thường quản lý quyền qua groups hoặc roles thay vì gắn policy trực tiếp cho từng user. Cách làm trong bài phù hợp cho việc thiết lập tài khoản học tập ban đầu.

### 5. Bật MFA cho IAMadmin

MFA bổ sung yếu tố xác thực thứ hai:

```
Password + mã MFA
```

Quy trình:

1. Mở phần Security credentials của `IAMadmin`.
2. Chọn Assign MFA device.
3. Chọn authenticator app hoặc thiết bị MFA phù hợp.
4. Quét QR code.
5. Nhập các mã MFA liên tiếp để AWS xác minh.
6. Hoàn tất và kiểm tra lại đăng nhập.

Nếu mật khẩu bị lộ, kẻ tấn công vẫn cần mã MFA đang hợp lệ.

> Với user có `AdministratorAccess`, MFA đặc biệt quan trọng vì user này gần như có toàn quyền trong tài khoản.
> 

### 6. Kiểm tra kết quả

Cuối bài:

1. Đăng xuất khỏi root.
2. Mở IAM sign-in URL có account alias.
3. Đăng nhập bằng `IAMadmin`.
4. Nhập mật khẩu và mã MFA.
5. Kiểm tra user có thể thực hiện công việc quản trị.

Từ đây, dùng `IAMadmin` thay cho root trong các bài thực hành và công việc quản trị thông thường.
