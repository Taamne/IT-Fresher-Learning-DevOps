## Course fundamentals and AWS

```
                 AWS
                  │
           ┌── AWS Account ──┐
           │                 │
       Identities         Resources
           │                 │
          IAM          EC2, S3, RDS...
           │
    ┌──────┼──────┐
   User   Group   Role
           │
      Permissions
        / Policy
```

**AWS Account: Account name, email, payment method ⇒ account Root User (quyền cao nhất) ⇒ nguyên tắc: không dùng user root cho công việc hằng ngày**

- Người dùng/quyền truy cập → **IAM (Identity and access management: hệ thống quản lý ai được phép làm gì trong AWS**
    - IAM user: một danh tính/ người dùng
    - IAM Group: nhóm nhiều user
    - IAM role : một danh tính có thể được “assume” tạm thời
    - IAM policy: quy định được phép làm gì
    - IAM access key: AWS có 2 kiểu làm việc phổ biến (Web, CLI/api), CLI/API cần cretentials: access key id, secret access key
        - cách dễ hiểu: username → access key id, password  → secret access key
        - nguyên tắc: Không hard-code Access Key vào source code.
- Máy ảo → **EC2 (so sánh dễ hiểu: proxmox VM ↔ AWS EC2 Instance**
- Object storage → **S3**
- Database → **RDS**
- Network → **VPC**
- Và rất nhiều dịch vụ khác.

**Multi-factor Authentication (MFA): Password + mã xác thực**
